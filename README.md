# zcode-review

Review local git changes as a GitHub-style HTML page.

## Problem

AI writes code faster than I can read it. Every session leaves a pile of changes, and `git diff` in a terminal doesn't cut it.

I just want to see what changed, mark what I've reviewed, and jot down notes. So this turns the git state into one HTML page I can open in a browser.

## Demo

[Live example](https://lukedaoo.github.io/zself-code-review/): a review of this repo's last commit, deployed to GitHub Pages.

## How to use

Install (symlinks the commands into `~/.local/bin`):

```bash
./install.sh
```

Run from any git repo:

```bash
zcode-review                      # working tree vs HEAD (includes untracked files)
zcode-review --base main          # vs merge-base(main, HEAD)
zcode-review --commits            # also one tab per commit
zcode-review --since last         # only what changed since the previous report
zcode-review --since HEAD~1       # last commit only
zcode-review --output out.html    # fixed output path
```

Reports go to `self-code-review/<date>/<date>_<HHMM>_<hash>.html`. Nothing is ever committed.

Live mode re-renders when files change:

```bash
zcode-review-watch review.html
```

In the report you can:

- switch unified / split view, pick a color theme
- filter files by status, viewed, or notes; search code (`/`)
- expand hidden context around a hunk
- mark files as viewed
- click a line number to add a note, then export notes as Markdown
- see warnings for secrets, debug leftovers, TODOs and trailing whitespace

## AI policy

All the code in this repo is generated by AI. I designed the idea and the architecture.

## Tech

- Python 3.11+, standard library only
- `git` for diffs (a temporary index, no commits or refs created)
- Vanilla JS and CSS, inlined into a single self-contained HTML file
- No build step, no dependencies
